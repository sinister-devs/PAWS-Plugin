Я хочу установить PAWS в тот ИИ-клиент, в котором мы сейчас общаемся, и подключить мой аккаунт приложения. Разрешаю добавить публичный каталог https://github.com/sinister-devs/PAWS-Plugin.git и установить из него только paws-app@paws-app в мои личные настройки. Настройки других плагинов сохрани.

1. Определи текущий клиент и ОС. Поддерживаются Codex и Claude Code на macOS, Windows и Linux в тех средах, где доступны локальные плагины. Проверь наличие Git, подходящей версии клиента и команд установки через его справку. Не устанавливай другой ИИ-клиент. Если нужной зависимости нет, дай один официальный способ её установки для моей ОС и дождись моего действия.
2. Прочитай README.md и docs/INSTALLATION.md публичного репозитория. Пакет не требует токенов GitHub, доступа к приватным репозиториям, Docker, Node.js или серверной установки. Не проси пароль PAWS, API-ключ или одноразовый код в чате.
3. Сначала проверь, не установлен ли PAWS. В Codex используй `codex plugin marketplace list --json` и `codex plugin list --json`. Для нового каталога выполни `codex plugin marketplace add https://github.com/sinister-devs/PAWS-Plugin.git`, затем `codex plugin add paws-app@paws-app --json`. Используй актуальную утилиту текущего приложения, а не случайную старую копию в PATH. В Claude Code проверь каталог и плагины, затем используй `claude plugin marketplace add https://github.com/sinister-devs/PAWS-Plugin.git` и `claude plugin install paws-app@paws-app --scope user`. Выполняй только ветку текущего клиента. Если каталог paws-app уже добавлен из другого источника, сначала покажи старый и новый источники и запроси согласие на замену; не создавай дубликат MCP и не удаляй другие подключения.
4. Проверь фактическую установку, включение и версию PAWS. Затем сразу выполни навык setup из установленного PAWS. Если инструменты ещё не появились, объясни необходимость нового чата и дай точный текст продолжения: «PAWS уже установлен. Выполни setup и вызови get_my_profile». Не выдавай установку за успешное подключение.
5. Используй штатную авторизацию встроенного MCP paws-app. Открой вход в моём браузере на web.pawsagent.app; я сам войду и нажму «Разрешить подключение». В Claude Code при необходимости предложи мне открыть /mcp и выбрать paws-app; в Codex используй штатный Connect/Authenticate или поддерживаемую команду mcp login. Не ослабляй проверку callback/issuer и не читай хранилища токенов. Адрес возврата с кодом не публикуй.
6. После авторизации реально вызови get_my_profile. Покажи моё имя, роль и организацию (или tenant_id с понятной подписью). Если роль или аккаунт не подходят, остановись и объясни точную причину. При ошибке сохрани её безопасное описание, а не сообщай, что всё готово.
7. После успешной проверки дай ссылку https://web.pawsagent.app/chat для создания учебного дела и попроси прислать адрес карточки /cases/<case_id>. Пока не создавай предложения, заметки или отчёты, не запускай платный анализ и не загружай мои локальные документы.

В конце кратко сообщи: что установлено, версия, результат настоящего get_my_profile и один следующий шаг. Непроверенные действия отмечай явно.
