Установи PAWS в текущий ИИ-клиент и подключи мой аккаунт.

Разрешаю установить только плагин paws-app@paws-app в мои личные настройки. Остальные плагины и подключения сохрани.

1. Определи текущий клиент и операционную систему. Проверь поддержку плагинов и наличие Git. Если нужна установка зависимости или обновление клиента, предложи штатный способ для моей ОС и дождись моего действия. Другой ИИ-клиент не устанавливай.
2. Используй источник https://github.com/sinister-devs/PAWS-Plugin.git. Сначала проверь существующую установку PAWS. Если источник уже добавлен, используй его; если он отличается, покажи старый и новый источники и согласуй замену.
3. В Codex используй актуальную утилиту текущего приложения: codex plugin marketplace add https://github.com/sinister-devs/PAWS-Plugin.git, затем codex plugin add paws-app@paws-app --json. В Claude Code используй claude plugin marketplace add https://github.com/sinister-devs/PAWS-Plugin.git, затем claude plugin install paws-app@paws-app --scope user. Выполняй только ветку текущего клиента и проверяй команды по его справке.
4. Подтверди, что PAWS установлен и включён, затем выполни его setup и запусти штатное подключение аккаунта. Я сам войду на web.pawsagent.app и нажму «Разрешить подключение». Пароль и коды в чат не запрашивай.
5. Вызови get_my_profile. Покажи имя, роль и организацию; если доступен только идентификатор организации, так его и подпиши. Если инструменты ещё не появились, дай текст для нового чата: «PAWS установлен. Выполни setup и вызови get_my_profile».
6. Считай подключение готовым только после успешного get_my_profile. Если произошла ошибка, сообщи её и следующий способ исправления. Пока не создавай и не изменяй дела.
