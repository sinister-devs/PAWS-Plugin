# Установка и обновление

Основной путь — [готовый промпт](../INSTALL_PROMPT_RU.md). Пользователь вставляет его в своего агента; команды ниже выполняет агент. Один публичный каталог содержит пакет для двух клиентов, но устанавливать нужно только в используемый клиент.

## Codex

Нужен актуальный Codex с командой `plugin` и Git. Проверьте `codex plugin --help`. В приложении может быть собственная свежая утилита, даже если в PATH осталась старая.

```text
codex plugin marketplace add https://github.com/sinister-devs/PAWS-Plugin.git
codex plugin add paws-app@paws-app --json
codex plugin list --marketplace paws-app --json
```

Затем: «PAWS, выполни setup и вызови get_my_profile». Если текущий чат не получил инструменты, начните новый. Сохранённый вход не нужно повторять без ошибки авторизации. Для входа используйте штатный Connect/Authenticate либо `codex mcp login paws-app`, если эта команда доступна в вашей версии.

Обновление из уже подключённого Git-каталога:

```text
codex plugin marketplace upgrade paws-app
codex plugin add paws-app@paws-app --json
```

## Claude Code

Нужны актуальный локальный Claude Code и Git. Команды оболочки:

```text
claude plugin marketplace add https://github.com/sinister-devs/PAWS-Plugin.git
claude plugin install paws-app@paws-app --scope user
claude plugin list
```

В интерактивном клиенте эквивалентны `/plugin marketplace add https://github.com/sinister-devs/PAWS-Plugin.git` и `/plugin install paws-app@paws-app`. После установки начните новую сессию, если клиент сообщает о необходимости перезагрузки. Вызовите `/paws-app:setup`; при запросе авторизации откройте `/mcp`, выберите сервер paws-app и пройдите браузерный вход. Готовность — успешный `get_my_profile`.

Обновление: `claude plugin marketplace update paws-app`, затем `claude plugin update paws-app@paws-app`. Команды сверьте с текущей справкой установленного клиента.

## ОС и доступ

Манифесты не содержат системных путей, команд запуска или исполняемых установщиков. Плагин соединяется с HTTPS-сервисом; на macOS, Windows и Linux используются те же адрес и идентификатор. Это не обещание наличия desktop-приложения каждого производителя на каждой ОС: на Linux используйте поддерживаемый CLI/локальный клиент. Облачная сессия `claude.ai/code` не заменяет локальную установку плагина. Установку и браузерный вход на каждой реальной ОС проверяйте отдельно; статическая проверка пакета не доказывает весь путь.

## Если что-то не получилось

- Каталог уже добавлен из другого источника: сначала определите его через список каталогов. Замена источника требует отдельного согласия; сохраняйте идентификатор плагина и другие настройки. Повторное добавление другого источника с тем же именем само по себе не мигрирует каталог.
- Клиент не знает команду plugin: обновите текущий клиент штатным способом. Не создавайте вручную второй сервер MCP вместо плагина.
- Ошибка `issuer` после браузерного входа: проверьте, что используется актуальная утилита клиента. Старый Codex 0.145.0 имел несовместимость с проверкой issuer; серверную защиту отключать нельзя.
- Нет доступа: войдите личным аккаунтом сотрудника PAWS. Роль выдаёт администратор PAWS; публичность репозитория на права не влияет.
- Неверный профиль: прекратите работу с делами, отзовите соответствующее подключение на https://web.pawsagent.app/connect и войдите правильным аккаунтом.
- Файл есть в приложении, но агент его не читает: сверьте case_id, список файлов и статус извлечения текста. Повторная установка плагина не исправляет обработку документа на сервере.

При обращении в поддержку укажите шаг, ОС, клиент/версию, время, безопасный текст ошибки и результат проверки профиля. Документы и номера рабочих дел передавайте только по внутреннему каналу поддержки.
