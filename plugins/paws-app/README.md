# PAWS

Разбирайте инциденты УЭЦН из Codex или Claude Code через свой аккаунт PAWS:
читайте материалы, сохраняйте наблюдения, гипотезы и проекты отчётов.

## Подключение

1. Установите плагин PAWS и выберите Connect / Authenticate.
2. В открывшемся приложении `https://web.pawsagent.app` войдите в свой существующий
   аккаунт и нажмите «Разрешить подключение».
3. Вернитесь в клиент и запустите навык `setup`: он проверит подключение
   вызовом `get_my_profile` и покажет ваш аккаунт и роль.

MCP endpoint уже входит в пакет. Копирование токенов, ввод API-ключей и
авторизация в GitHub для этого подключения не требуются. Модель и подписку
определяет используемый клиент; плагин подключает инструменты PAWS.

В Claude Code штатная авторизация MCP доступна через `/mcp` → `paws-app` →
Authenticate. В Codex используйте подключение аккаунта в карточке плагина.

Текущий MCP предоставляет инструменты личным аккаунтам сотрудников PAWS.
Общие аккаунты и роль заказчика к этим инструментам не подключаются.
Плагин сохраняет действующие права приложения и изоляцию организаций.
Утверждение выводов выполняет человек в PAWS.

| Навык | Назначение |
|---|---|
| `setup` | Проверить подключение и действующий аккаунт |
| `investigate` | Разобрать материалы дела и сдать проект отчёта |

Отозвать доступ клиента: https://web.pawsagent.app/connect → «Отключить».
При истечении подключения или отзыве повторите Authenticate из клиента.

## Версия 0.2.2

Иконка и логотип плагина используют утверждённый знак PAWS. Этот же PNG
показывается на экране разрешения подключения после выкладки веб-приложения.
Пакет доступен через публичный каталог PAWS-Plugin; публикация в общем поиске клиентов — отдельный процесс. После установки выполните
setup: только успешный `get_my_profile` подтверждает рабочее подключение.
