---
name: setup
description: Подключить ваш аккаунт PAWS после установки плагина или восстановить истёкшее подключение.
disable-model-invocation: true
---

1. Найди встроенный MCP `paws-app` в инструментах текущего клиента. Если требуется авторизация, запусти штатное действие Authenticate/Connect этого сервера. В Claude Code пользователь открывает `/mcp` и выбирает `paws-app`; в Codex — карточку подключения плагина PAWS. Адрес сервера уже входит в пакет.
2. Передай пользователю браузерный вход на `web.pawsagent.app`. Он входит в существующий аккаунт PAWS и разрешает подключение. Если пользователь уже вошёл, повторный ввод пароля может не потребоваться. Пароли и коды вводятся только в приложении PAWS.
3. После возврата клиента вызови `get_my_profile` у этого MCP. Покажи имя, роль и организацию из ответа; если вместо названия доступен только tenant_id, подпиши его «Идентификатор организации». Не придумывай название. При отказе сохрани точную причину и предложи повторить штатную авторизацию; не выдавай подключение за готовое.

Готово, когда реальный вызов `get_my_profile` вернул вошедшего пользователя. Затем попроси номер дела для работы. Инструкции разбора доступны в навыке `investigate`.

Если инструменты ещё не загрузились в текущий чат, сохрани короткий текст продолжения для нового чата: «PAWS уже установлен. Выполни setup и вызови get_my_profile». Не дублируй сервер и не переписывай настройки других плагинов.
